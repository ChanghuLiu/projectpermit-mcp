# Outreach Batch 08 — high-leverage upstream funnels + build-vs-buy falsification

Sent / updated: 2026-08-28

## Purpose

This batch is deliberately different from broad contractor outreach.

It targets Canadian software/marketplace workflows where project scope already exists **before contractor quote/selection** and asks one of two falsification questions:

1. **E2 density:** Is there a bounded >=500/month current-family workflow where permit applicability is still unresolved upstream?
2. **Build-vs-buy:** When a platform already publishes permit guidance, does it prefer maintaining rules internally or buying a deterministic evidence-linked capability?

No reply counts as validation merely because it is positive. Automated acknowledgements remain E0.

## Evidence classification rule

A countable E2 response from a volume target requires:

- recent bounded timeframe;
- geography/workflow definition;
- denominator or bounded denominator bucket;
- incidence/location of permit-applicability uncertainty in the workflow.

A countable build-vs-buy signal requires a product/platform decision-maker or sufficiently informed operator to state whether external rule maintenance would or would not be considered and why.

Neither category automatically becomes E3/E4/E5.
