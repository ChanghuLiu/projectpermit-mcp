## Why historical cases are stronger than opinion replies

A contractor saying `this sounds useful` is only E1.

A historical-case set can be independently checked against:

- the contractor's reported actual permit outcome;
- ProjectPermit's deterministic result;
- current first-party municipal guidance;
- disagreement category;
- false-negative risk;
- whether municipality-specific logic materially changes the safe answer.

The desired E3 output is therefore not trust in the respondent's product opinion. It is a reproducible confusion matrix over representative real work.

## Current municipal differentiation anchor

Official current guidance already supports a useful Ontario example:

- Toronto explicitly exempts a basic house-basement finish when there is no structural/material alteration, no new dwelling unit and no new plumbing;
- Ottawa publishes a dedicated `Finishing a basement` permit workflow.

This does **not** count as E3 because it is official-rule/synthetic market-structure evidence rather than representative contractor history.
